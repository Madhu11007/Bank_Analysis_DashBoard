#  Bank Analysis Dashboard | Microsoft Excel

##  Project Overview
Developed an interactive Bank Analysis Dashboard using Microsoft Excel to analyze customer data, account balances, loan-related information, and customer demographics. The dashboard provides meaningful insights through visualizations and interactive filters.

##  Project Objectives
- Analyze customer demographics and banking information.
- Understand customer distribution based on job, marital status, and education.
- Track customer balances and age distribution.
- Identify patterns in customer data through interactive visualizations.
- Support data-driven decision-making.

##  Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Data Analysis

##  Dashboard Features
- **KPI Cards:** Total Balance, Total Age, Count of Clients, Count of Education, and Number of Marriages.
- **Column Chart:** Customer distribution by job and marital status.
- **Pie Chart:** Customer distribution by education.
- **Line Chart:** Monthly analysis of balance and age.
- **Doughnut Chart:** Customer distribution by marital status.
- **Area Chart:** Balance analysis by job and previous outcome.
- **Stacked Column Chart:** Education-wise customer distribution.
- **Interactive Slicers:** Job and marital status filters.

##  Key Insights
- Analyzed customer distribution across different job categories.
- Compared customer marital status and education levels.
- Examined balance trends across monthly periods.
- Identified patterns in customer demographics.
- Used interactive filters to explore specific customer segments.
